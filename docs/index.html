功能特性

项目分类管理

新建、双击改名、一键删除；8 色编号徽标循环标识，一目了然。

待办任务

点击圆圈完成（带淡出动画）、单击文字编辑、回车连续新增，流畅顺手。

中文输入法跟随

拼音组合窗口与候选列表跟随光标，Win7 / Win11 输入法均正常，候选弹层与界面风格一致。

自绘 UI 与动画

Direct2D 硬件加速渲染；5 种归位动画、关闭淡出、图标悬停旋转、高亮渐变。

设置面板

开机自启、标题前缀（最多 5 个汉字）、归位动画切换，一键生效。

数据持久化

todos.json / config.json 每次操作即时写入，零第三方依赖，删除即可重置。

轻量单文件

约 395 KB 单 exe，/MT 静态链接，不依赖 VCRedist，拷走即用。

平台兼容

Windows 7（SP1 + Platform Update）与 Windows 11，支持高 DPI 显示。
